# Architecture Decision Records (ADRs)

Registros de decisões de arquitetura tomadas durante o desenvolvimento do RazeGas Backend.

## Como criar um novo ADR

1. Copie `TEMPLATE.md` para `NNN-nome-da-decisao.md`
2. Preencha todos os campos
3. Status inicial: `Proposed`
4. Após revisão e aprovação: mude para `Accepted`

## Status

| Status | Significado |
|--------|-------------|
| `Proposed` | Decisão proposta, em revisão |
| `Accepted` | Decisão aprovada e em vigor |
| `Deprecated` | Decisão substituída por uma posterior |
| `Superseded` | Decisão substituída por um ADR mais recente |
